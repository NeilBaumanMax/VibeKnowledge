# v4：先建立符号含义，再展示筛选

用户反馈：黄框、金灰粒子和连线的含义无法从观看中理解。v3的知识表达自审过于乐观，应撤回这一项“已经讲清楚”的判断。

本次不改飞机、音乐、流动粒子及逐字字幕的技术方案。修改限定为：

1. 0–2秒：在粒子空间旁明确“每个点，都是一个人”，建立点与人的对应。
2. 金点汇聚时：框上方出现“你看到的成功者”。标签与框一起移动，明确颜色、结果和观察范围的关系。
3. 2秒以后：灰点上方出现“没被看见的失败者”。镜头聚焦时这批点和标签退到视野外，拉远后重新进入。
4. 删除11–16秒全部分叉线、传播线和空心端点。不再要求观众解码未定义的线路。
5. 11.3秒字幕调整为“同一种方法，也有人失败”；13.7秒调整为“你却只看见了成功者”，与两类有名称的群体对应。
6. 17秒扩展观察范围时，框标签改为“完整样本”，说明框的变化。
7. 标签也采用逐字上滑；不恢复品牌角标和进度装饰。

验收分开记录：技术与画面检查可以给通过/失败数量；“首次观看是否理解”必须保留待用户复核，不能用源码意图、帧率或位移测量替代。
