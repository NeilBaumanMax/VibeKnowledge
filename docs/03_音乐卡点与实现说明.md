# 实际配乐与卡点（覆盖初始无音乐方案）

用户在制作过程中提供《千年之后（氛围版）》OGG，已采用该文件，没有使用先前设想的合成配乐。

- 原始文件：`film/assets/audio/source.ogg`，174.413 秒，Vorbis，44.1kHz，12 声道。
- 实际分析：先解码，计算短时能量、35–180Hz 低频包络、频谱正向差分和节奏自相关。
- 检测节拍估计：103.68 BPM（约104 BPM）。这是算法估计，不作为每个剪辑点的唯一依据。
- 清晰段落起音：原曲 18.562812 秒。
- 本版取样区间：原曲 1.562812–31.562812 秒，速度保持 1.0。
- 该段落起音对应样片 17.000 秒，第510帧。文字在该帧即出现，随后约0.27秒收敛锁定。
- 16.03–16.65 秒视觉收暗；不对原曲强行插入静音或改变节奏。
- 转为 48kHz 双声道 WAV，响度目标 -16 LUFS，真峰值目标 -1.5dBTP。开头35ms去点击，样片末尾0.5秒淡出。最终实测见验收报告。
- 主要字幕和图形变化靠近检测起音，允许帧级取整；长文字不追随每个小节拍跳动。
- 该音乐是用户提供的第三方曲目，本项目不将它记为原创或自动推定发布授权。

## 文件与重渲染

在工作区根目录运行：

```bash
node tools/build.mjs
./tools/hf.sh check
./tools/hf.sh preview --background
./tools/hf.sh render --quality delivery --fps 30 --workers 1 --output ../output/幸存者偏差_30秒样片.mp4
```

`tools/hf.sh` 使用工作区内FFmpeg/FFprobe并把渲染临时文件存放在 `review/`，单工作进程适应本机8GB内存。HyperFrames版本固定0.8.186，GSAP固定3.14.2。

字幕编辑 `film/src/captions.json`；样式编辑 `film/src/styles.css`；飞机编辑 `film/src/aircraft.js`；粒子编辑 `film/src/particles.js`；场景节奏编辑 `film/src/timeline.js`。修改后运行构建脚本；不要只改生成的 `film/index.html`。

音乐更换后，重新生成 `music-cues.json` 和 `score.wav`，调整字幕时间和场景交接时间，再检查17秒附近帧与实际音频起音。

准确时序以 `docs/02_实际字幕时间轴.csv` 和 `film/src/captions.json` 为准。最初逐秒分镜表达叙事意图；实际卡点可有小幅帧级调整。
