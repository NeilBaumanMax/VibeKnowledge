# 叙事实例：幸存者偏差

这是独立的文字参考，不是运行依赖或必须复用的故事。

核心命题：只看经过结果筛选的成功样本，漏掉失败者，会误判某种方法的有效性；成功经验可以参考，但不能据此认定普遍有效。

|时间|文字/知识动作|视觉意义|
|---|---|---|
|0–4秒|你看到的成功／其实筛掉了无数失败|少量金点从完整样本被注意力突出；灰点仍存在|
|4–8秒|为什么成功经验常常误导你？|放大成功标签，再拉远发现被忽视的群体|
|8–16秒|同一种方法，也有人失败|同一观察空间内的不同结果，框明确表示观察范围|
|17秒|幸存者偏差|从收暗恢复完整样本，配合真实起音逐字揭晓|
|19–30秒|返航飞机上出现弹孔，另一架关键部位中弹后无法进入统计|返航本身构成样本选择；图形明确标注原理示意|
|30–41秒|研究中弹后的风险；弹孔少不自动等于危险|考虑致命薄弱部位、命中条件与损失信息，不只比孔数|
|41–59秒|同一种方法，有人成、有人成不了|框只纳入成功者会漏掉另一种结果；两组有相邻标签|
|59–69秒|完整样本，还要比较条件|框扩展，提醒起点、资源、时机|
|69–78秒|你看到的经验，可能只是幸存者的回声|回到开头同一群体，呼应最初的问题|

相关历史依据：Wald研究备忘录（1943，CNA于1980重印），https://www.cna.org/reports/1980/0204320000.pdf 。教学飞机、弹孔及成功/失败数量是示意，不是真实统计图。不虚构Wald台词。

适用于其他主题的经验：让观众先看见对象及结果，再随动画观察遗漏/条件，最后用文字确认概念。颜色和对象身份保持一致；文字有整句阅读时间；不能只给一个漂亮但不知含义的框。
